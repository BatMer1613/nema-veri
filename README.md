# Nema Hesaplama — veri dosyası

Nema Hesaplama Android uygulamasının herkese açık güncelleme verisi ve gizlilik politikası.
Uygulama bu depodaki `veri.json` dosyasını yalnızca **okur**; kullanıcı verisi gönderilmez.

- `veri.json` — memur katsayıları, nema oranları, aylık TÜFE, asgari ücret, emekli zamları
- `gizlilik.html` — gizlilik politikası (GitHub Pages)
- `GUNCELLEME_REHBERI.md` — veri dosyasının nasıl güncelleneceği

Bu uygulama bağımsızdır; OYAK veya MSB ile resmi bağı yoktur.
